        FAQ

        How do breaks work?

        Tray icon with a countdown tooltip. Right-click: Start break now, Demo (30s), postpone, Settings, quit. A fullscreen overlay runs the timer; you can skip early.

        Why isn’t the app signed by Apple?

        Cat Break is distributed without an Apple Developer ID signature. macOS Gatekeeper may block the first launch — that is expected, not a broken download.

        Install from DMG or ZIP
        1. DMG: open the image, drag Cat Break to Applications.
        2. ZIP: unzip (often Downloads), then move Cat Break.app to Applications before daily use.

        Requires macOS 12+. Pick arm64 on Apple Silicon, x64 on Intel.

        “Damaged” app or quarantine (Terminal)

        Damaged while Cat Break.app is still in Downloads? Do not click Move to Trash — run the first command below.

        App in Downloads (typical after ZIP):

        xattr -cr "$HOME/Downloads/Cat Break.app"

        After moving to Applications:

        xattr -cr "/Applications/Cat Break.app"

        Adjust the path if the unzip folder name differs.

        Open without Terminal

        Right-click Cat Break.app → Open → Open again. Or System Settings → Privacy & Security → Open Anyway.

        Launch at login

        Enable Launch at login in the app Settings.

        FAQ

        Как работают перерывы?

        Иконка в строке меню и таймер во всплывающей подсказке. ПКМ: Начать перерыв, Демо (30 сек), отложить, Настройки, выход. Полноэкранный оверлей с отсчётом, можно завершить досрочно.

        Почему нет подписи Apple?

        Сборка без Apple Developer ID. Gatekeeper может заблокировать первый запуск — это ожидаемо, а не «битый» файл.

        Установка: DMG и ZIP
        1. DMG: откройте образ, перетащите Cat Break в Программы.
        2. ZIP: распакуйте (часто Загрузки), затем перенесите Cat Break.app в Программы.

        Нужен macOS 12+. На Apple Silicon — arm64, на Intel — x64.

        «Повреждено» и quarantine (Терминал)

        Окно «повреждено» и приложение в Загрузках? Не нажимайте «Переместить в Корзину» — выполните первую команду.

        Приложение в Загрузках (типично после ZIP):

        xattr -cr "$HOME/Downloads/Cat Break.app"

        После переноса в Программы:

        xattr -cr "/Applications/Cat Break.app"

        Подставьте свой путь, если папка после распаковки называется иначе.

        Открыть без Терминала

        ПКМ по Cat Break.app → Открыть → Открыть. Или Системные настройки → Конфиденциальность и безопасность → Всё равно открыть.

        Автозапуск

        Tray icon not visible

        FAQ

        How do breaks work?

        Status tray icon, right-click menu, fullscreen break overlay. Wayland support depends on your desktop environment.

        AppImage or .deb

        AppImage: chmod +x Cat_Break-*.AppImage then run.
        .deb: sudo dpkg -i cat-break_*_amd64.deb, launch from the app menu or cat-break.

        Tray icon missing

        Install AppIndicator support (libayatana-appindicator3-1 on Ubuntu/Debian). On GNOME you may need a tray extension.

        X11 vs Wayland

        X11 is the most reliable. On Wayland, overlay and tray behavior can vary by compositor.
