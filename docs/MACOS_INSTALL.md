# Установка Cat Break на macOS

## Требования

- macOS 12+
- macOS 12+
- Готовые сборки в Releases: **arm64** (Apple Silicon) и при необходимости **x64** (Intel)
- Сборка Intel на Mac: `npm run dist:mac -- --x64`

## Скачать готовую сборку

1. Возьмите файл `Cat Break-*-arm64.dmg` из [Releases](https://github.com/anatoly-kulishov/CatBreak/releases) (или соберите сами).
2. Откройте DMG и перетащите **Cat Break** в **Программы**.

## Первый запуск (без подписи Apple)

Приложение **не подписано** Apple Developer ID. macOS может заблокировать запуск.

**Способ 1:** ПКМ по `Cat Break.app` → **Открыть** → **Открыть**.

**Способ 2:** Терминал:

```bash
xattr -cr "/Applications/Cat Break.app"
open "/Applications/Cat Break.app"
```

**Способ 3:** **Системные настройки** → **Конфиденциальность и безопасность** → **Всё равно открыть**.

## Запись экрана (опционально)

Для размытого фона на перерыве: **Системные настройки** → **Конфиденциальность и безопасность** → **Запись экрана** → включить **Cat Break**.

## Ошибка «не удаётся открыть из-за проблемы»

Не подписывайте `.app` вручную через `codesign --deep` — это ломает Electron Framework.

Используйте сборку из репозитория или Releases без дополнительной подписи.
